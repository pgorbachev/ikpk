# Инструкции проекта

@AGENTS.md

Этот файл существует только как точка входа: правила проекта живут в `AGENTS.md`,
общем для всех инструментов, а Claude Code читает `CLAUDE.md`. Импорт выше
подключает `AGENTS.md` целиком — дублировать правила здесь нельзя, иначе две копии
разойдутся и станет неясно, какая главная.

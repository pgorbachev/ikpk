# Свидетельство: объём данных при резервном копировании

Свойство `PROPERTY_BACKUP_VOLUME` (`openspec/changes/server-provisioning`, tasks.md,
раздел 0, исключение 2). Ручная приёмка — на одноразовом контейнере данных нет
(design.md, Решение 2).

Ревизия объявленного состояния, к которой привязано это свидетельство: `1`
(`deploy/environments/stand.env`, `PROVISION_REVISION`).

Статус: НЕ ПРОВЕДЕНО. Требует стенда с реальными данными системы управления. Порядок:

1. Наполнить `CMS_DATA_DIR` реальными данными.
2. Снять копию (`BACKUP_ONLY=1 scripts/bootstrap-vps.sh <host>`).
3. Сверить объём и число файлов копии с объёмом и числом файлов каталога данных.
4. Записать команду, дату, объём (байт, число файлов) сюда, заменить статус на
   «ПРОВЕДЕНО».

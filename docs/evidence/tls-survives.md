# Свидетельство: сертификаты переживают провижининг

Свойство `PROPERTY_TLS_SURVIVES` (`openspec/changes/server-provisioning`, tasks.md,
раздел 0, исключение 1). Ручная приёмка — контейнер не воспроизводит `certbot` с
настоящим доменом (design.md, Решение 2).

Ревизия объявленного состояния, к которой привязано это свидетельство: `1`
(`deploy/environments/stand.env`, `PROVISION_REVISION`).

Статус: НЕ ПРОВЕДЕНО. Прод ещё не поднят (`openspec/specs/online-payment/spec.md:1689`,
«production API — объём отдельного будущего change»), поэтому проверить нечем.
Как только на стенде или проде появится настоящий домен и сертификат:

1. Убедиться, что `https://<домен>/` отвечает 200 до запуска провижининга.
2. Запустить `scripts/bootstrap-vps.sh <host>`.
3. Убедиться, что `https://<домен>/` отвечает 200 после — тем же содержимым.
4. Записать команду, дату и вывод сюда, заменить статус на «ПРОВЕДЕНО».

# Каталог статей до и после: дата и порядки сортировки (D22, D25)

Предмет — два запроса заказчика с демо 2026-08-19: убрать даты выкладки с карточек (D22) и
убрать сортировку по алфавиту (D25). Требования — дельта change `article-list-pagination`.

**Вариантов здесь нет намеренно.** Мокапы в нескольких вариантах нужны, когда выбирается
облик; здесь элементы **удаляются** из уже утверждённой раскладки, и выбирать не из чего.
Так записано в `design.md` того же change. Снимки до/после нужны, чтобы удаление было
видно глазами, а не только по зелёному тесту.

- снято с настоящих сборок: `after` — эта ветка, `before` — сборка `main` того же дня
- вьюпорты 1280×900 и 375×812, `deviceScaleFactor=1`, `reducedMotion=reduce`
- скрипт: [`shot-statyi.mjs`](shot-statyi.mjs)

Машинный протокол съёмки:

```
before desktop: порядков 4 (Сначала новые | Сначала старые | По названию А–Я | По названию Я–А), <time> в карточках 6
after  desktop: порядков 2 (Сначала новые | Сначала старые),                                     <time> в карточках 0
```

## Что видно на снимках, кроме снятых элементов

**Лид карточки перестал повторять заголовок и дату.** Это не косметика сверх задания: у
всех 68 статей `body_text` начинается служебной шапкой «Заголовок ДД мес., ГГГГ | Автор»,
приехавшей из скрейпа. Сняв только нашу подпись `<time>`, мы оставили бы дату выкладки
видимой на всех 68 карточках — то есть выполнили бы D22 по букве и не выполнили по сути.

Имя автора в лиде осталось: между `|` и телом статьи разделителя нет, и угадывать, где
кончается имя, значило бы резать текст по догадке. На первой карточке из-за этого имя
видно дважды — так устроен исходный текст статьи, а не наша обработка.

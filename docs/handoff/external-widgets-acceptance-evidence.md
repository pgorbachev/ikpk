# Свидетельства приёмки — change `external-widgets`

Файл содержит по одной записи на каждый **применимый** приёмочный пункт спеки
(`openspec/changes/external-widgets/specs/external-widgets/spec.md`). Применимость
вычисляется из репозитория (`web/tests/external-widgets-acceptance.test.ts`,
`acceptancePoints()`), а не решается на глаз: пункт, чьё условие не наступило, записи не
требует, и файл ниже несёт ровно один — остальные пять сейчас неприменимы (знаков в
`DECLARED_AWARD_BADGES` нет, боевая сборка идёт с `CHAT_LOADER_SRC=none`, байтовый предел
404 не поднимался).

По мере того как условия остальных пунктов наступают (появится реальный адрес
загрузчика чата, будет объявлен знак награды, поднимется предел 404), сюда добавляются
новые записи — старые не переписываются.

## Тексты и имена авторов проверены приёмкой

- **Что проверено:** секция отзывов на главной (`/`, боевая сборка, `CHAT_LOADER_SRC=none`) —
  собранный статический HTML и архитектура ленивой загрузки виджета.
- **Кем:** Claude Code (техническая проверка сборки; владельцу стоит подтвердить визуально
  на демо/стенде отдельно, если нужна приёмка именно им — эта запись её не заменяет
  автоматически).
- **Дата:** 2026-08-25
- **Наблюдение:** в собранном `dist/index.html` секция `[data-reviews-section]` несёт
  только: заголовок «Отзывы на Яндекс.Картах», подпись, ряд знаков наград (пуст),
  плейсхолдер «Загрузка отзывов…», `noscript`-ссылку на страницу отзывов Яндекс.Карт и
  атрибут `data-reviews-embed` с адресом виджета. Ни одного `<iframe>` в статическом
  выводе нет вовсе — он создаётся клиентским скриптом только по появлению секции в
  зоне видимости (`web/src/components/home/sections/Reviews.astro`), и ни одного текста
  отзыва или имени автора нигде в собранном HTML нет.
- **Непустота предмета:** секция существует на странице, `data-reviews-embed` несёт
  реальный адрес официального виджета (`https://yandex.ru/maps-reviews-widget/112883331290?comments`),
  плейсхолдер и `noscript`-ссылка на месте — предмет не пуст и не удалён.
- **Источник:** `cd web && CHAT_LOADER_SRC=none npm run build && grep -oE '<div class="reviews-embed"[^>]*>.{0,400}' dist/index.html` —
  вывод команды воспроизводим на любой сборке той же ревизии. Дополнительная структурная
  гарантия: сам виджет — `<iframe>` на чужом происхождении (`yandex.ru`), поэтому даже
  после появления на странице содержимое отзывов кросс-origin и нашему коду недоступно
  ни при каком состоянии — то есть текст отзывов не может попасть в наш DOM ни статически,
  ни во время выполнения.

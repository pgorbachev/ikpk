# Предложения по переносу сведений о документах

`prepare.py` читает только проверенный снимок и поимённую карту `manifest.json`. Он создаёт приватный JSON-отчёт, содержащий исходный HTML и ссылки, хеши панели и снимка, маршрут, document ID, версию правил и структурированное предложение. Источник — опубликованные панели 13.11.2026, а не подтверждение актуальности владельцем. Скрипт не подключается к CMS и не применяет данные. Наличие предложения не означает разрешение на автоматическую запись.

```sh
python3 scripts/document-migration/prepare.py fixtures/content-snapshot/collapsible_panels.json /private/path/new-report.json
python3 -m unittest discover -s scripts/document-migration -p 'test_*.py' -v
```

Отчёт создаётся вне репозитория, с правами 0600 и только если файл ещё не существует. Снимок, маршрут и хеш каждой панели проверяются до создания отчёта; при расхождении выполнение прерывается. ID взяты из редакторской сверки снимка, а не проверены по живой базе. Перед любой будущей записью отдельно необходимы проверка соответствия текущего маршрута и ID, совместимости утверждённой схемы, источника и отсутствия последующих редакторских изменений; этот инструмент не выполняет эти проверки.

Группа 3 сохраняет перечисленные исходы и исходную ссылку; назначение этой ссылки требует ручной проверки, поскольку её фрагмент ведёт к соседнему разделу. Группы 11 и 12 содержат только общий факт «документы», явно помеченный как неизвестный вид, и ссылку на следующий семинар: конкретный документ с другой страницы не копируется. Схема и импорт находятся в разработке; это не готовая запись и не замена ревью каждого факта и ссылки.

# Черновой конвертер текстов семинаров

Это **только подготовка предложений**, не миграция и не разрешение на запись. Код не обращается к БД. Сохранность реальных записей, routes, документов, регистрации, медиа и якорей, а также итогового renderer/sanitizer не доказана. Правила намеренно распознают только ограниченное подмножество HTML и точную простую форму Radix; реальные legacy-оболочки, документы, незнакомые элементы, атрибуты, порядок, заполненные дополнительные поля и неоднозначности блокируют запись. Формы и расписание автоматически не вырезаются. Правила должны расширяться только с доказательствами покрытия и тестами. Статус `ready` означает лишь, что предложение построено; он не означает готовности к применению или публикации.

Запуск на подготовленном JSON, содержащем массив `{ "source": {...}, "sidecar": {...} }`:

```
python3 scripts/seminar-content-conversion/dry_run.py /private/input.json /private/new-report.json
python3 -m unittest discover -s scripts/seminar-content-conversion -p 'test_*.py' -v
```

Отчёт содержит исходный и предлагаемый текст, ссылки и медиа, поэтому хранить его приватно; файл не перезаписывается. Для исключений сохраняются идентичность, fingerprint и причины, исходный JSON хранится отдельно. Результат воспроизводим; применение, проверка поступивших правок, транзакция, журнал, rollback, сверка связей и публикации не реализованы.

`source` содержит `document_id`, `version` (`draft`/`published`), точный `path`, `description` и существующие `full_text`, `audience`, `learning_plan`, `learning_mode`, `recommendations`; все дополнительные ключи также входят в отпечаток. Отдельный `source` требуется для каждой физической версии; следует передать `id` и `locale`. Для свёрнутой панели sidecar имеет вид `{ "panels": {"/path": {"Учебный план": "<p>...</p>"}}, "pin": {"source_sha256": "...", "panels_sha256": "..."} }`. Оба отпечатка — SHA-256 JSON с `ensure_ascii=False`, `sort_keys=True`, `separators=(',', ':')`, UTF-8; вычислить можно функцией `fingerprint` из `converter.py`. Хеши фиксируют содержимое и версию, но **не доказывают происхождение** sidecar: источник и соответствие версии должны быть независимо подтверждены до формирования pin. Нельзя создавать pin просто потому, что совпал путь.

Для распознанных разделов отчёт содержит исходный фрагмент, целевые поля, происхождение, отпечатки и предполагаемую карту якорей. Сравнение не эмулирует сайт и не доказывает корректность отображения или сохранность входящих ссылок: оно требует ручной и машинной проверки на фактических renderer/sanitizer и доказанного происхождения. Обработанные встроенные панели предпочитаются sidecar, как в текущем рендере; документы оставляются на отдельное решение. Не публиковать отчёты с содержимым и персональными данными.

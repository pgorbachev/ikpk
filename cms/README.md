# CMS ИКПК (Strapi)

Команды запускаются из каталога `cms/`:

```sh
npm ci
npm run develop   # локальная разработка
npm run build     # сборка административной панели
npm run start     # запуск CMS
npm test          # тесты CMS
npm run lint
npm run typecheck
```

Порядок выпуска и допуска к установке описан в [релизном процессе](../docs/release-process.md).
Общие инструкции публикации — в [runbook](../docs/deploy-vps.md), установка на демостенд —
в [отдельном runbook](../docs/runbook-stand-demo-install.md).

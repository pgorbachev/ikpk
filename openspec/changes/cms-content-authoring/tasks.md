## 8. Адреса, перенаправления, снятие с публикации

- [ ] 8.1 Смена идентификатора или связи опубликованной записи не роняет сборку и порождает
      постоянное перенаправление со прежнего адреса
- [ ] 8.2 Перенаправление с легаси-адреса ведёт на текущий адрес одним переходом; цепочки не
      накапливаются
- [ ] 8.3 Генерация правил перенаправления перестаёт быть разовым артефактом и учитывает
      текущие адреса записей; правил с несуществующей целью в сборке нет
- [ ] 8.4 Снятая с публикации запись исчезает из списков, расписания и карты сайта; ссылок на
      её адрес нет ни на одной странице

## 9. Триггер публикации

- [ ] 9.1 Аутентифицированный запрос из CMS запускает существующий обязательный прогон на
      вершине основной ветки
- [ ] 9.2 Перечень событий: публикация, изменение опубликованной записи, снятие с публикации,
      удаление, изменение медиафайла опубликованного контента
- [ ] 9.3 Параметры запроса не влияют на собираемое; неаутентифицированный запрос игнорируется
- [ ] 9.4 Очередь на один ожидающий прогон без отмены текущего; серия правок сходится к
      публикации последнего состояния
- [ ] 9.5 Сверка на случай потерянного оповещения: расхождение опубликованного состояния с
      контентом обнаруживается без участия оповещения
- [ ] 9.6 Ручная публикация выкладывает проверенную пару либо последнюю проверенную версию;
      при отсутствии проверенной пары отказывает и не собирает из живой CMS

## 11. Гейты и негативная проверка

- [ ] 11.1 Для каждого нового гейта негативная проверка в своём worktree: вернуть дефект,
      убедиться, что покраснел **именно** этот гейт (судить по имени теста, а не по цвету
      прогона)
- [ ] 11.2 Записать каждую мутацию воспроизводимо: точная команда или патч плюс два числа —
      до и после
- [ ] 11.3 Подтвердить восстановление постусловием под предмет мутации: для отслеживаемых
      файлов — пустой `git status --porcelain` и отсутствие diff к опорному SHA; для
      сгенерированного вывода — контрольная сумма дерева по относительным путям с сортировкой

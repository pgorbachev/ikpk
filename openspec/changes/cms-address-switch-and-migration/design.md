истории адресов и переносе остаются в design.md исходного change и после его архива — в

## Goals / Non-Goals

**Goals:** переключить канонический адрес целиком и перенести контент без потерь.

**Non-Goals:** схема системы управления, роли, медиа, формы — это исходный change.

## Предварительная SQL DEMO193-фаза

Предварительная фаза PR #186 (D4 + D23-data + D3-data) создаёт отдельную CMS-базу и data release
офлайн из неизменяемого SQL baseline и отдельно разрешённых публичных медиафайлов. DEMO193 —
только целевая демонстрационная база: её текущее содержимое не используется как источник,
поверхность для повторного импорта или overlay. Ручные изменения и три ручных семинара в DEMO193
не смешиваются с SQL baseline. У этой фазы нет backup/restore DEMO193.

Исходный SQL и приватный data release хранятся приватно в локальном Git. В публичный репозиторий
попадают только конвертер, синтетические фикстуры и очищенные спецификации. Приватный manifest
фиксирует source и target metadata ID, соответствие source→target и хеши кода, трансформации и
данных. Неизвестные или неподдерживаемые публичные поля и медиа перечисляются как именованные
исключения; тихая потеря данных запрещена. Документные файлы проходят отдельный allowlist и не
считаются растровыми медиа. Текущие количества для сверки: Institutes 3, Teachers 31, Programs 26,
Articles 68, Seminars 132. Срез Events на 2026-10-12: 280 active, из них 271 с active parent и
58 current/future; это инвентарные значения, а не фиксированный фильтр миграции. Значение 29 в
прежней подписи числа персон устарело; классификация персон остаётся
первичной и передаётся владельцу/заказчику на подтверждение.

SQL адаптера в репозитории пока нет; этот план описывает будущую поставку и не утверждает, что
адаптер или приёмка уже реализованы. Раздельный SQL data этап может быть выполнен до полной D7
поставки, не архивируя родительский change и не закрывая полную миграцию. Его зависимости — только
PR #186 на явно утверждённой точной ревизии, RED/GREEN-проверки, независимые code/security/pony
reviews, свежий CI и сверки точных пар кода и data snapshot. Требования полной поставки ниже,
включая защиту правок заказчика и атомарность источника, остаются в силе и не считаются
выполненными demo-прогоном. Изменения адресов и production не входят в эту фазу.

Неопределённые решения остаются открытыми: замена изображения Barrallogore ещё кандидат, а не
утверждённое соответствие; отсутствующие в источнике контакты, статические страницы, авторы и
даты, видео и конфликты преподавателей требуют отдельного решения, без выбора по умолчанию.
Первичная классификация персон по фактическим active ID также не является окончательным
подтверждением владельца.

## Decisions

- **Переключение адресов неделимо.** Перенаправления, ссылки, `canonical`, карта сайта и снятие
  `noindex` выкладываются одной поставкой. Любой частичный порядок выводит записи из индекса либо
  оставляет два индексируемых адреса у одной страницы.
- **Красные тесты хранятся в каталоге change**, а не в `web/tests/`: PR с красными тестами в
  `main` не сливается, а удалить их значило бы выбросить оплаченную работу. При активации они
  возвращаются в `web/tests/` (задача 0.2).

## Risks / Trade-offs

- Дельта написана до появления основной спеки: при активации её надо пересобрать (задача 0.1),
  строгая валидация расхождения не покажет.

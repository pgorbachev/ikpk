## Context

Форма телефонов имеет собственную серверную проверку роли и не даёт content-admin общих прав на Page.

## Goals / Non-Goals

Сделать вход в форму понятным для обеих ролей, сохранив прежние границы доступа.

## Decisions

Супер-администратор открывает контакты через существующий список страниц. Администратор контента получает пункт «Страницы», ведущий к узкой форме контактов. Самостоятельная иконка телефона удаляется.

## Risks / Trade-offs

Добавление пункта в меню не должно давать общих прав на API Page. Нужна проверка другой роли и прямых вызовов API.

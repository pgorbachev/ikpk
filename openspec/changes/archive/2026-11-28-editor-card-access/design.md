## Context

Приложение синхронизирует права Editor при запуске. Форма телефонов использует собственный маршрут с проверкой роли. Strapi объединяет публикацию и снятие с публикации одним разрешением.

## Goals / Non-Goals

Разрешить правку содержимого карточек и публикацию изменений. Сохранить адреса, права других ролей и границы формы телефонов.

## Decisions

Задать права на поля в существующем списке Editor. Проверять снятие с публикации на сервере. Допустить Editor к действующей форме телефонов без разрешений на коллекцию Page. В аудите миграции принять точную дельту разрешений этой роли.

## Risks / Trade-offs

Перед production проверить на 194 целевую роль и сохранность записей. Штатная парная поставка сохраняет предыдущую пару для восстановления.

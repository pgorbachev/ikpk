## 2. Согласование с пересекающимися изменениями

      требование прямо говорит, что документация положения не заменяет. Назвать его вне

- [ ] 2.3 Отложить реализацию до приземления изменений, тоже правящих состав `Tests`:
      `deploy-gated-on-tests` с демо-сборкой и baseline каталога статей. Перед реализацией
      **перечитать** `test.yml` из слитого состояния, а не опираться на снимок
- [ ] 2.4 Подготовить предложение для `dependabot-auto-merge`: сделать работающий гейт
      предусловием включения авто-слияния. Оформляется отдельным `/opsx:update`, решение

- [ ] 7.5 Негативно проверить различение состояний: удалить эталон одной тройки — прогон
      красный и эталон не создан
- [ ] 7.6 Негативно проверить манифест окружения: исказить одно поле — прогон красный и
      называет поле

      контрольная сумма дерева (`find . -type f -exec shasum {} + | sort | shasum`) либо
      пересборка

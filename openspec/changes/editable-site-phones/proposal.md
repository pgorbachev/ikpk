## Why

Телефон центра и мобильный менеджера сейчас меняются через выпуск кода. Редактору нужны два независимых поля в существующей записи Page → Контакты сайта, чтобы менять каждый номер один раз для всего сайта.

## What Changes

- Добавить поля «Телефон центра» и «Мобильный телефон менеджера», заполнив их действующими номерами при переходе.
- После публикации записи и успешного «Обновить сайт» подставлять каждый номер во все его текущие места, включая таблицы сведений об организации, ссылки для звонка и поисковую разметку.

## Capabilities

### New Capabilities

- `site-contact-phones` — редактирование и публикация двух общих телефонов сайта.

### Modified Capabilities

## Impact

Изменение затрагивает модель Page в Strapi, переход существующих данных, снимок статических страниц, сборку Astro и проверки опубликованного HTML. У медцентра также есть свой отдельный городской номер с окончанием 54-60. Эта задача охватывает городской с окончанием 54-50 и общий мобильный.

## ADDED Requirements

### Requirement: Метаданные карточки ссылки

Все существующие подробные страницы программ, семинаров и статей, включая вложенные адреса, SHALL отдавать в исходном HTML по одному тегу `og:title`, `og:description`, `og:image`, `og:url`, `og:type`, `og:site_name`, `og:locale`, `og:image:width`, `og:image:height` и `og:image:alt`. `og:url` SHALL совпадать с каноническим адресом страницы, `og:site_name` — с «ИКПК», `og:locale` — с `ru_RU`. У статьи тип SHALL быть `article`, у программы и семинара — `website`.

#### Scenario: Задана опубликованная обложка ссылки

- **WHEN** в опубликованном SEO-компоненте записи задано индивидуальное изображение
- **THEN** тег `og:image` содержит абсолютный публичный HTTPS-адрес этого изображения, а теги размеров соответствуют фактическому файлу
- **AND** альтернативный текст соответствует описанию из медиатеки или, при его отсутствии, обозначает обложку этой страницы

#### Scenario: Индивидуальная обложка не задана

- **WHEN** опубликованный SEO-компонент не содержит обложку ссылки
- **THEN** карточка использует общую картинку ИКПК, даже если у записи есть основное изображение
- **AND** теги размеров и альтернативного текста относятся к общей картинке

### Requirement: Отдельные тексты карточки в CMS

SEO-компонент Strapi для трёх типов записей SHALL предоставлять необязательные поля «Open Graph Title» и «Open Graph Description». Опубликованные значения SHALL применяться независимо друг от друга только к соответствующим OG-тегам.

#### Scenario: Заполнено только одно поле

- **WHEN** редактор публикует непустое значение одного OG-поля, а другое поле отсутствует, пустое или содержит только пробелы
- **THEN** карточка использует заданное значение для первого поля и действующее SEO-значение страницы для второго
- **AND** обычные SEO-заголовок и описание страницы сохраняются

#### Scenario: Снимок предшествует появлению новых полей

- **WHEN** строится сайт из ранее сохранённого снимка без новых полей
- **THEN** сборка завершается и использует соответствующие SEO-значения и доступную обложку по общему правилу

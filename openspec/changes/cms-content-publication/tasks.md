- [x] 4.1 Неизменяемый журнал: запись на событие изменения контента — номер из возрастающей
      последовательности, отпечаток контента, номер предшествующей записи, маркер события; плюс
      высшая достигнутая отметка, не уменьшающаяся при операциях с базой
- [x] 4.1a **Каноническая форма отпечатка:** детерминированный порядок типов, записей, связей и
      ключей; перестановка объектов в ответе, другое разбиение на страницы и другой порядок ключей
      отпечаток не меняют. Негативная проверка: перемешать порядок в ответе — отпечаток тот же
- [x] 4.1b **Отпечаток привязан к событию, а не прочитан позже:** состояние берётся из транзакции
      этого изменения либо привязывается к глобальной ревизии источника. Проверка: два быстрых
      сохранения дают две записи с **разными** отпечатками (наивный обработчик даст оба по
      последнему состоянию)
- [x] 4.2 Снимок несёт **два** числа: номер **наблюдённой записи** журнала (последняя запись на
      момент снятия) и **производную** ревизию контента. Ревизия: новое содержимое и ручной
      возврат текста → номер новой записи; опознанное восстановление базы → номер первой записи с
      тем же отпечатком (ниже отметки); восстановление с **неизвестным** журналу отпечатком →
      ревизия не определяется, нужно подтверждение
- [x] 4.2a Маркер **«принятие состояния»**: подтверждение восстановленной базы записывает запись,
      и принятое содержимое получает ревизию на уровне новой отметки. Проверка: после принятия
      обычный календарный прогон идёт без подтверждения, а следующий откат — снова с ним.
      Запись создаётся **только** для состояния системы управления, не для ручной выкладки старой
      пары
- [x] 4.3 Негативная проверка на этот случай: после восстановления базы гейт публикации обязан
      покраснеть. Прежние редакции делали это недостижимым **дважды** — сначала правилом
      «совпадение отпечатка не подменяет номер», потом сравнением устаревания по ревизии вместо
      наблюдённой записи; проверка обязана ловить оба возврата
- [x] 4.4 Совпадение отпечатка без маркера требует подтверждения человеком
- [x] 4.5 Журнал не переписывается; попытка изменить или удалить запись отклоняется
- [x] 4.6 Сохранность журнала входит в резервное копирование; недоступный или пустой журнал при

- [x] 4.7 Маркер восстановления ставится процедурой восстановления базы (действие вне системы

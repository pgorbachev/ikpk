## Why

Парная публикация и кнопка обновления сайта из CMS на staging194 подменяют ссылки записи на семинары заглушками. Ручное переключение указателя вернуло нужный HTML, но housekeeping не может сопоставить активный релиз с подлинной записью о публикации.

## What Changes

- Парная публикация и обновление сайта из CMS на 194 будут выводить адреса записи для конкретного проведения из снимка CMS. Временные адреса, согласованные владельцем, действуют как обычные значения CMS.
- Оба пути до переключения сайта будут сверять CTA кандидата со снимком и разрешать ссылки только в согласованных местах. Оплата, чат, аналитика и индексация останутся отключёнными для этой конфигурации.
- Публикация по обоим путям формирует штатную историю релизов и проходит обычную проверку перед очисткой.

## Impact

Сборка Astro, парный staging194 helper, worker обновления сайта и приёмка HTML. Сборки production и демо со своими действующими настройками сохраняют текущую политику. Приёмка стенда считывает HTML и проверяет административный интерфейс без отправки регистрационных форм.

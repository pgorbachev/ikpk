- [ ] 3.2 Удалить хранимое поле статуса из схемы семинара
- [ ] 3.3 Множественное медиа-поле у семинара, программы, института

- [ ] 3.5b Три формы представления охвата: строка с документом, строка «документы не выдаются»,

- [ ] 3.6 Связь преподавателя с институтом; адрес его страницы выводится из связи

## 7. Развёртывание CMS

- [ ] 7.1 Развернуть Strapi и PostgreSQL на VPS, админка за nginx
- [ ] 7.1a **TLS для админки и её API:** доменное имя, сертификат, перенаправление с
      незащищённого протокола, признак «только по защищённому соединению» у cookie сессии.
      Отдельным пунктом, потому что нынешний bootstrap пишет vhost с одним `listen 80`
      (`scripts/bootstrap-vps.sh:72`, `listen 80;`), а HTTPS в инструкции развёртывания —
      необязательный шаг; панель в таком vhost отдаёт пароль администратора открытым текстом
- [ ] 7.2 Бэкапы базы и загруженных файлов, проверенные восстановлением — **инфраструктурная
      задача без спекового предмета**: требования о резервном копировании в спеке нет и не
      предполагается, поэтому сессия красных тестов её не покрывает; проверка ручная, со
      свидетельством
- [ ] 7.3 Адреса админки и API получают `no-store`; общее правило для адресов вне классов на них
      не распространяется — проверка по тексту конфигурации плюс свидетельство по живой раздаче
- [ ] 7.4 Закрыть или ограничить доступом advisory prod-дерева `cms` до вывода админки в
      интернет; измерить состав заново на момент развёртывания
- [ ] 7.5 Зафиксировать выбор по доступу заказчика: журнал происхождения (change
      `cms-content-publication`) введён до первой правки **либо** доступ к редактированию закрыт
      до его введения. Правки в промежутке ни в одну запись журнала не попадают, и восстановление
      раннего резервного копирования после них выглядит новым состоянием, а не откатом

## 8. Перенос контента

- [ ] 8.1 Импорт: идемпотентность по легаси-идентификатору **и по содержимому медиа**, ненулевой
      код выхода при потерянной записи, оборванной связи и неудачной загрузке, счётчик неудачных
      загрузок, явный флаг обхода (закрывает TD-8)
- [ ] 8.1c Защита правок заказчика при повторном переносе: запрет редактирования на время
      переноса либо проверка неизменности целевой ревизии перед обновлением; при расхождении
      перенос останавливается и называет запись
- [ ] 8.1a Повторный запуск **доводит или заменяет** частично перенесённую запись, а не считает её
      готовой по факту существования легаси-идентификатора: иначе запись, на которой упал прогон,
      остаётся сломанной навсегда при «успешном» переносе
- [ ] 8.1b Разделить существующие 445 оригиналов: те, на которые ссылается перенесённый контент,
      становятся записями медиатеки; остальные остаются материалом сборки в репозитории с явно
      названной ролью
- [ ] 8.2 Перенести контент; разовая сверка адресов подтверждает совпадение вычисленного и
      прежнего адреса
- [ ] 8.3 Семинары без исходных сведений о документах получают состояние «сведения не
      подтверждены»; вывод «не выдаются» из отсутствия сведений запрещён
- [ ] 8.4 Исчерпывающая карта «адрес и заголовок панели → поле сущности» для 96 страниц и 39
      заголовков; перенос останавливается на заголовке вне карты
- [ ] 8.5 Перенести содержимое записей-заплаток расписания либо назвать отброшенные с причиной.
      **Само удаление модуля из сборки — не здесь:** он подмешивается в страницу расписания
      (`web/src/pages/raspisanie-i-tseny.astro:61`, `...scheduleSupplements.filter(`), а чтение
      из системы управления вводит change `cms-content-publication`. Снять модуль раньше значит
      удалить события у посетителя; проверку «удалённое в системе управления событие не
      возвращается, статус семинара пересчитан» выполняет соседний change после переключения
      источника
- [ ] 8.6 Сверка рендера тел до и после переноса; расхождение — дефект переноса
- [ ] 8.7 Зафиксировать выбор: заморозка редактирования старого сайта или атомарная выгрузка.
      Для выгрузки — **и таблицы, и медиа**: транзакционный дамп покрывает только таблицы,
      поэтому к нему нужен снимок хранилища, доказанная неизменяемость файлов или отметка по
      байтам медиа, сверяемая до и после обхода
- [ ] 8.7a Идемпотентность против правок редактора: прогон переноса сохраняет ревизию или
      контрольную сумму, которую сам записал, следующий прогон сравнивает с **ней**, а не с
      прочитанным в этом же прогоне; расхождение останавливает перенос и называет запись
- [ ] 8.8 Заключительная сверка перед передачей источника соседнему change: число записей по
      типам, значения полей, целостность связей, состав медиа, **обнаружение удалений**

- [ ] 1.1 Провести независимое ревью черновика и получить согласование владельца:
  удаление поля, сохранение исторического значения только для повторов, ограничение
  восстановления без снимка и границы обновления `payment-seminar-picker`.
- [ ] 1.2 До тестов и кода согласовать артефакты `payment-seminar-picker` по перечню
  в `proposal.md`, сохранив исторические свидетельства. Проверить обе дельты строгой
  валидацией и совместным применением в одноразовом worktree к актуальной основной
  спецификации; устранить восстановление старых требований при последующем архиве picker.

## 2. Реализация и проверки после согласования

- [ ] 2.1 Добавить проверки сценариев дельты: DOM без места, новый запрос с null,

  разные удержания и переназначение идентификатора, новая оплата после старой,
  повтор при утраченном снимке. Проверять запросы и сохранённые данные, а не только DOM.
- [ ] 2.2 Удалить блок места из формы; реализовать выбор значения для payload и
  сохранение исторического места по текущей попытке без скрытого элемента.
- [ ] 2.3 Пройти целевые проверки формы и повторов, релевантные гейты web и серверную

  и широком экране, включая повторное открытие и клавиатурный обход.
